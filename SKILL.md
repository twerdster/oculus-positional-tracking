# Maintaining this archive

Read SUMMARY.md, then this file, README.md and PROVENANCE.md before editing.

- Preserve the original presentation and historical image byte for byte. Record file hashes when checking identity. Keep any future translations, repairs, ports or reconstructed code separate and clearly labeled.
- Keep the archived student credits and the public profile links supplied by each student. Do not publish private correspondence or personal contact addresses.
- Separate the slides' architecture and historical equipment descriptions from verified code or runtime behavior. API declarations in a presentation do not establish a working implementation, and the 120 Hz Vicon description is not a reproduced performance result.
- Audit any newly supplied files, including notes, metadata, original raster images and embedded objects, before publication. An archival permission response does not create a software or third-party-image license.
- Check Markdown links, rendered images and staged whitespace, then review and synchronize SUMMARY.md and this file before committing. Follow the existing normal Git publication workflow.
