# Oculus positional tracking archive

This public repository documents Dor Goldbaum and Vlady Ostrovski's historical RiftFusion project, supervised by Aaron Wetzler. It keeps the archived figure and the video link from the existing project record. Vlad supplied the same historical video URL on 13 November 2026; YouTube oEmbed metadata identifies its title and channel, but the video contents remain unreviewed. This adds provenance, not runtime validation or recovered source.

On 12 November 2026, Vlad agreed to the archival record and supplied his public LinkedIn link. Dor supplied his own public LinkedIn link and the original 13-slide Hebrew presentation. On that date, Vlad reported having no surviving project material; Dor could not find the code. Vlad's later reply supplied the video link only. The README links the students' supplied profiles while retaining the archived student-name spelling.

The unmodified presentation is preserved as original/RiftFusion-Presentation.pptx (1,172,371 bytes; SHA-256 6631c2bb787df645265b7cf9831714e7c1cf9b1aa729c26879c951abc2fd04cd). PROVENANCE.md records recovery, file identity and review scope. The slides describe KinectFusion and Vicon tracking, a position server, provider/consumer components and TCP/IP API declarations. Their qualitative comparison and stated 120 Hz Vicon rate are historical claims, not reproduced benchmarks.

No code, build configuration, executable or tracking dataset is present. All slides were reviewed from a LibreOffice rendering, and all four uncropped original embedded images were inspected directly. Notes, metadata and package relationships were also inspected. No tracking runtime or headset test was performed. Keep original material unchanged, and keep private correspondence outside this repository.
