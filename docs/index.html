Each displayed frame is a generated sample index, not a measured hardware timestamp or output rate. Delay is applied to the generated trajectory before deterministic noise is added; the filter computes pₜ = αsₜ + (1 − α)pₜ₋₁. Smoothing reduces rapid variation and introduces lag. It does not establish how the original tracking providers performed.
